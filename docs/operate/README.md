# Operate kgcache

[Docs](../README.md) / Operate

Run a standalone kgcache service with settings and storage chosen for your
workload. If you only want to try commands, start with the
[quick start](../get-started/README.md).

## Set up a service

1. [Run with Docker or Compose](docker.md), or [install the native executable](../get-started/install.md).
2. [Configure the listener and data paths](configuration.md).
3. [Choose a persistence mode](persistence.md).
4. [Limit network access](security.md).

## Keep it running

- [Check health and inspect connections](monitoring.md).
- [Stop, restart, and replace a process](shutdown.md).
- [Troubleshoot a failed start or request](troubleshooting.md).

Use the [configuration reference](../reference/configuration.md) to look up
defaults and accepted values. The [compatibility reference](../reference/compatibility.md)
lists supported features and capacity limits.

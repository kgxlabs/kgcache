# Reference

[Docs](../README.md) / Reference

Look up the exact behavior of the current server. The
[application guides](../develop/README.md) show how to use it, and the
[operation guides](../operate/README.md) show how to run it.

- [Commands](../commands/README.md): syntax, options, examples, and replies.
- [Compatibility](compatibility.md): exact tested clients, supported features,
  exclusions, and automated coverage.
- [Protocol](protocol.md): request grammar, reply encodings, limits, and
  connection behavior.
- [Configuration](configuration.md): every supported directive, its default,
  accepted range, and input grammar.

These pages describe `main`. They do not infer compatibility with an untested
client version or with every Redis feature.
